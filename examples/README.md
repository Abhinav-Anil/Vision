Examples
========

Quick ways to run the demos from the repository root:

Run the `illusion` motion logger:

```
python run_demo.py --script illusion
```

Run the bounding-box demo (opens a Bokeh graph after you quit):

```
python run_demo.py --script vision_bounding
```

Record the simple video demo:

```
python run_demo.py --script vision_video
```

Notes:
- These demos open your webcam and display GUI windows. Press `q` (or as indicated) to quit.
- Ensure dependencies are installed: `pip install -r requirements.txt`.
